## Session 1 — 2026-05-19

### Stack deviations from the handoff (intentional, locked in)

| Area | Handoff said | What we actually did | Why |
|---|---|---|---|
| shadcn CLI | Radix UI primitives | `@base-ui/react` (shadcn v4.7.0) | Latest CLI changed underlying primitive library; API is identical |
| Fonts | `next/font/google` with `Geist` | `geist` npm package (`GeistSans`, `GeistMono`) | `Geist` not available in `next/font/google` on Next.js 14 |
| react-day-picker | v8/v9 assumed | v10 installed | `table` className key renamed to `month_grid` in v10; fixed in calendar.tsx |
| Auth middleware | Single `lib/auth.ts` for both | Split: `auth.config.ts` (edge-safe) + `lib/auth.ts` (Node-only) | bcryptjs is not Edge Runtime compatible; middleware must use edge-safe config only |
| `globals.css` | Clean design tokens | shadcn init removed `--background`/`--foreground` from unlayered `:root` | Fixed by re-adding them; unlayered `:root` beats shadcn's `@layer base` oklch values via CSS cascade |
| `form.tsx` | Generated by shadcn CLI | Hand-written react-hook-form wrapper | Not in new shadcn registry; standard implementation |

| Area | Handoff said | What we actually did | Why |
|---|---|---|---|
| Prisma enum syntax | Single-line `enum Foo { A B }` (from overview) | Multi-line, one value per line | Prisma PSL does not support single-line enum definitions — parser errors |
| `badge.tsx` | Extend shadcn with `kind`/`color` props | Rewrote — dropped `@base-ui/react` `useRender`/`mergeProps` entirely | Plain React component is simpler; polymorphic render API adds nothing for badge usage |
