# Logo Explorations — archived

Six directions were explored. **D — Gauge arc** was chosen and is now the working logo in [`../`](../).

| File | Direction | Why it didn't win |
|---|---|---|
| `A-card.svg` | Card | Generic fintech / credit-card cliché. |
| `B-pocket.svg` | Pocket pouch | Most literal, but visually busy at small sizes. |
| `C-ledger.svg` | Open ledger | Skewed business-formal — wrong register for "homelab personal app." |
| **`(chosen)`** | **D — Gauge arc** | Echoes the dashboard's income-used meter; most product-native; scales beautifully. |
| `E-coin-monogram.svg` | Coin monogram (P) | Strong as a favicon, but felt heavier than the brand wanted. |
| `F-receipt.svg` | Receipt | Charming but reads as "transaction log" rather than "money instrument." |

Kept here for reference in case we need to revisit.
